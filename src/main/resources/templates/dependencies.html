🔗 Task Dependencies

Define which tasks must complete before others — builds the Directed Acyclic Graph (DAG).

🧠 DAG — Directed Acyclic Graph

A dependency means "Task B cannot start until Task A is complete." The system builds a DAG from these rules and uses Kahn's Topological Sort for the execution order. Circular dependencies are automatically rejected.
